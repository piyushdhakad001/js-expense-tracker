# Expense Tracker 💸

A clean, responsive, and persistent web-based expense tracking application built with vanilla JavaScript, modern CSS, and LocalStorage.

## Live Demo
🔗 [View Live Application](https://piyushdhakad001.github.io/js-expense-tracker/)

## Features
- **Add Expenses:** Record item names, transaction dates, and precise monetary amounts.
- **Persistent Storage:** Automatically saves your expense history using browser `localStorage` so data isn't lost on refresh.
- **Dynamic Calculation:** Instantly updates and totals all recorded expenses in real-time.
- **Item Removal:** Easily delete individual entries with automatic recalculation of the total balance.
- **Responsive Design:** Clean layout optimized for both desktop and mobile screens.

## Tech Stack
- **HTML5** (Semantic markup)
- **CSS3** (Flexbox, custom styling, responsive media queries)
- **JavaScript (ES6+)** (DOM manipulation, array methods, event handling, LocalStorage API)
